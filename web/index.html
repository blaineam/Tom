    Start a station from Siri, a Shortcut or CarPlay
    1. Pick a station above, then copy its start link:
    2. In the Shortcuts app, make a new shortcut with Open URLs and paste the link. Name it something like "Jazz Radio" and Siri will run it when you say its name.
    3. The link opens Tom and writes the first song. iPhone asks for one tap before a web page can start playing: tap anywhere on the screen (or press play on the lock screen).
    4. Once it's playing, it shows up in Now Playing on the lock screen and in CarPlay, with pause, next and previous on the car's screen and steering-wheel buttons.
